# De Gierbloemen - Login Pagina

Een moderne login pagina gebouwd met Next.js en React, met een prachtig groen kleurenschema.

## 🚀 Features

- **Moderne UI/UX**: Schone, professionele interface met groene kleuren
- **Responsive Design**: Werkt perfect op alle apparaten
- **Animaties**: Subtiele animaties voor betere gebruikerservaring
- **Form Validatie**: Client-side validatie voor e-mail en wachtwoord
- **Loading States**: Visuele feedback tijdens het inlogproces
- **Accessibility**: Toegankelijke formulier elementen

## 🎨 Kleurenschema

- **Primair Groen**: #10B981
- **Secundair Groen**: #34D399
- **Accent Groen**: #A7F3D0
- **Donker Groen**: #064E3B
- **Licht Groen**: #ECFDF5

## 🛠️ Technologieën

- **Next.js 14**: React framework met App Router
- **TypeScript**: Type-safe development
- **Tailwind CSS**: Utility-first CSS framework
- **React Hooks**: Moderne state management

## 📦 Installatie

1. Installeer dependencies:
```bash
npm install
```

2. Start de development server:
```bash
npm run dev
```

3. Open [http://localhost:6001](http://localhost:6001) in je browser

## 🎯 Gebruik

De login pagina bevat:
- E-mail validatie
- Wachtwoord veld met show/hide functionaliteit
- "Onthoud mij" checkbox
- "Wachtwoord vergeten" link
- Registratie link
- Loading states tijdens het inlogproces

## 🔧 Development

- **Port**: 6001 (geconfigureerd om conflicten te voorkomen)
- **Hot Reload**: Automatische herlaad bij wijzigingen
- **TypeScript**: Volledige type ondersteuning
- **ESLint**: Code kwaliteit en consistentie

## 📱 Responsive

De pagina is volledig responsive en werkt op:
- Desktop (1024px+)
- Tablet (768px - 1023px)
- Mobile (320px - 767px)

## 🎨 Animaties

- Fade-in animaties voor content
- Float animaties voor decoratieve elementen
- Hover effecten op interactieve elementen
- Loading spinners voor feedback
